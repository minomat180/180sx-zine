# Security

This is a personal fan site, not a product. There are no accounts. The only
user data is what people type into the chat (a display name and messages),
which the chat room keeps in memory while it is awake and never writes to
storage. Fonts are loaded from Google Fonts.

If you find a problem with 180sx.tech or the chat endpoint, open a GitHub
issue, or use GitHub's private vulnerability reporting on this repository if it
should not be public yet.
