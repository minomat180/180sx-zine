Privacy Policy - pi Gmail Access

Last updated: 9 November 2026

"pi Gmail Access" is a private tool used by the owner of 180sx.tech to manage their own Gmail account from the command line (searching, archiving, labelling, and cleaning up their own mail). It is not offered to the public and has no other users.

What data it accesses

With the account owner's consent, the tool uses the Gmail API to read message metadata and content and to modify labels (for example archiving, marking as read, or moving to Trash) in the owner's own mailbox.

How the data is used and stored

Data is processed only on the owner's own computer, only to carry out the owner's mailbox actions. The OAuth token is stored locally with owner-only file permissions. No data is sold, shared with third parties, used for advertising, or used to train AI models. Nothing is stored on any server operated for this tool.

Google API Services User Data Policy

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
